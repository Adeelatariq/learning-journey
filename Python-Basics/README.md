# Python Basics — Movie Ticket Sales Practice

A small script I wrote while starting the Python section of the Google Advanced 
Data Analytics Certificate, after a semester of C++ coursework.

## What it does
Calculates revenue from adult and youth movie ticket sales using variables, 
basic arithmetic, and Python's `type()` function to check data types.

## What I practiced
- Assigning and using variables
- Checking data types with `type()`
- Basic arithmetic and print formatting

## Notes
Coming from C++, the biggest adjustment has been Python's indentation rules 
and remembering the colon (`:`) after conditional/loop statements — small 
syntax habits I'm still building.
