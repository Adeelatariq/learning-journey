# Python Data Structures & Core Libraries Practice

This folder contains practice notebooks covering fundamental Python data structures, sequence manipulation, and core scientific computing libraries for the **Google Advanced Data Analytics Certificate**.

---

## 📌 Topics Covered

- **Strings:** Manipulation, slicing, formatting, and common string methods.
- **Lists & Tuples:** Creation, indexing, immutability vs. mutability, and operations.
- **Dictionaries:** Key-value mappings, methods, and data retrieval techniques.
- **Arrays & NumPy:** Vectorized operations, multi-dimensional array manipulation, and mathematical methods.
